 DaisyUI

 Next.js Image
 Vercel

##  Features

  Browse different workouts
  View detailed information about each workout
  Create and manage today's workout plan
  Save workouts to a personal save plan
  Remove workouts from the saved plan
  Toast notifications for user actions
  View workout details including muscle groups, equipment, difficulty, duration, sets, reps, and calories burned
 Fully responsive design for mobile, tablet, and desktop
  Display workout ratings
 Optimized images using Next.js Image






##  Responsive Design

The application is designed to work on:

  Mobile devices
  Tablets
  Laptops
  Desktop screens
